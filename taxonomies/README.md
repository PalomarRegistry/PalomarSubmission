# Classification snapshots

- `arxiv-categories.json` contains the category identifiers and names published in the
  [arXiv category taxonomy](https://arxiv.org/category_taxonomy).
- `msc2020-codes.json` contains the five-character classification identifiers and names
  published by [MSC2020](https://msc2020.org/).

These taxonomy snapshots were retrieved on 2026-08-01. MSC2020 is
jointly published by Mathematical Reviews and zbMATH under
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/), which
applies to `msc2020-codes.json`. Update the snapshots when either official
taxonomy changes.
